# BÀI 1 – KIỂM TRA MÔI TRƯỜNG NODE.JS

**Sinh viên:** Võ Tiến Đạt  
**Lớp:** CĐ-CNTT18B

### 1. Môi trường thực hành

Bài thực hành được thực hiện trên máy tính cá nhân sử dụng Windows 10 Pro 22H2. Công cụ lập trình là Visual Studio Code và môi trường thực thi JavaScript là Node.js.

### 2. Kiểm tra môi trường

Sau khi cài đặt Node.js, em sử dụng Terminal trong Visual Studio Code để kiểm tra:

- Lệnh `node -v`: hiển thị phiên bản Node.js v26.13.0.
- Lệnh `npm -v`: hiển thị phiên bản npm 11.20.0.

Kết quả cho thấy Node.js và npm đã được cài đặt và có thể sử dụng trên máy tính.

### 3. Xây dựng chương trình đầu tiên

Em tạo tập tin `hello.js` bằng JavaScript. Chương trình sử dụng hàm `console.log()` để xuất thông tin ra Terminal, bao gồm lời chào, thông tin sinh viên, phiên bản Node.js và hệ điều hành đang sử dụng.

Chương trình được thực thi bằng lệnh `node hello.js`.

### 4. Kết quả thực hiện

Sau khi chạy chương trình, Terminal hiển thị đầy đủ nội dung đã khai báo. Chương trình kết thúc bình thường, không phát sinh lỗi.

Qua thực hành, em đã hiểu được cách sử dụng Node.js để chạy một tập tin JavaScript trực tiếp mà không cần trình duyệt.

### 5. Nhận xét

Qua bài thực hành đầu tiên, em đã làm quen với môi trường Node.js, cách kiểm tra phiên bản phần mềm và phương pháp thực thi chương trình thông qua Terminal. Đây là bước chuẩn bị để tiếp tục tìm hiểu cách xây dựng ứng dụng và kết nối cơ sở dữ liệu MongoDB ở các bài tiếp theo.
